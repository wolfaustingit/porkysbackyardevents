# porkysbackyardevents

Live events calendar for **Porky's Backyard** (5131 Atascocita Road, Humble, TX 77346) —
a sister site to [porkysbackyard.com](https://porkysbackyard.com).

One stylized page that renders the venue's Google Calendar. Styling ports the main
site's design system (Chewy display type, `#FF1E02` red, `#FFF8F6` cream).

Astro, static output, deployed to Cloudflare from `main` — same pattern as the
`conroebc` and `timberforestbp` sites.
